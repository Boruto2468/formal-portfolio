# Next.js + TypeScript portfolio

Run `npm install && npm run dev` and open http://localhost:3000.
For production, run `npm run build && npm run start`.

The original HTML design is preserved in `components/PortfolioContent.tsx` as JSX. Cursor drawing and ink effects are implemented in `lib/effects.ts` and mounted in `components/CursorEffects.tsx`. For details, see `../README.md`.
